# Archive

Superseded report-generation scripts, kept for thesis reference only (not part of the active pipeline).

- `generate_profiling_docx.py` — early academic-style profiling report generator, predates the per-step `docs/reports/<step>/generate_*.py` scripts.
- `convert_report_to_docx.py` — early `weekly_report_step2.md` → `.docx` converter, superseded by the same per-step pattern used in `docs/reports/step3_6/` and `docs/reports/step7/`.

Current reports are generated by the script colocated with each report under `docs/reports/<step>/`.
